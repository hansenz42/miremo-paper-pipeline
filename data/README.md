# Attention 示例数据

论文：[Attention Is All You Need](https://arxiv.org/abs/1706.03762)，Vaswani et al., 2017。正文为提取文本，图示以原论文入口代替。论文内容归原作者所有，不属于代码的 MIT 授权范围。

数据来自 Miremo 在 2026-10-24 保存的历史模型处理链：994 条算法候选，经细读补充后为 998 条候选，全部有模型判断记录，最终整理为 160 条术语。保留未采纳状态，不能视为经过人工全面核验的金标准。模型用量未在此投影中汇总，界面不将占位数值显示为实际用量。

图示元数据形成的噪声候选保留 ID 和模型判断，原名称中的内部文件标识已脱敏。字段仅投影论文、术语、模型判断和证据；不包含账号、连接配置或内部类型标识。每个精确高亮位置均对照原分片文本验证。缺少精确位置的模型发现项只定位证据段落。
